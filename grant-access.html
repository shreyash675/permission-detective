🔍 Permission Detective needs access to your Salesforce API domain

Salesforce serves the Lightning UI from *.lightning.force.com, but the REST API — and the session that authenticates it — lives on *.my.salesforce.com. Permission Detective needs read access to that domain's session cookie to analyze permissions.

Your browser currently only grants access to the Lightning domain. Because you never actually browse to the API domain, the browser never offers to grant it — so it has to be granted here.

  • https://*.my.salesforce.com/*
  • https://*.salesforce.com/*
  • https://*.lightning.force.com/*
