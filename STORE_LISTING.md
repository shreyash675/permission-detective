## Detailed description (1000 characters max)

```
Permission Detective answers the question every Salesforce admin dreads:
"Why can't this user see or edit this field?"

Open any Lightning record, click Permission Detective, enter the field and
the user you're troubleshooting, and get a full breakdown in seconds:

- Record-level access (Read/Edit/Delete/Transfer) via UserRecordAccess
- Field-Level Security per Profile and Permission Set
- Object-level CRUD per Profile and Permission Set
- A visual chain showing exactly where access is blocked - Object CRUD,
  FLS, or record-level sharing

No more juggling Profile settings, Permission Sets, sharing rules, and role
hierarchy across five Setup tabs. It queries your org's own metadata and
shows the exact Profile or Permission Set responsible for each grant or
denial.

Runs entirely against your own org using your existing session - no
external servers, no data collection, no separate login required.

Built for admins, architects, and support engineers debugging access
issues.
```
